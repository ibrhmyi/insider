# Contributing, corrections and removal

PMITC welcomes new cases, corrections and removal requests. Please use the issue templates (`.github/ISSUE_TEMPLATE/`):

- **Submit a case**: a public source (URL) that alleges, charges, sanctions or analyses suspected informed trading on a prediction market, naming a specific account, wallet, cluster or market (PROTOCOL 4).
- **Correct a row**: the row id (`claim_id`, `wallet` + `case_id`, `condition_id`) and the evidence. Claims are never edited: a correction becomes a new claim or a row in `contradictions`.
- **Request removal**: the row id and the reason (for example, the only source was retracted, or the row identifies you). See `docs/DATA_PROTECTION.md`.

## Response policy
- Acknowledgement within 7 days, decision within 30 days.
- A row whose only source is retracted is removed. A credible identity concern is handled first and privately; rows can be withheld while a request is reviewed.
- Every change is logged as a new run with its amendment (PROTOCOL.md) and noted in `docs/CHANGELOG.md`.
- New cases are added under the protocol (graded, sourced, never guessed); a case is never added because a detector flagged it.
